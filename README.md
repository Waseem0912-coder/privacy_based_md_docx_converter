# MD DOC Converter (Private Markdown to DOCX)

## Problem
LLMs generate output in Markdown, but there is no simple privacy-first tool to load highly confidential Markdown and convert it to DOCX locally.

## Solution
This project is a local-first Markdown to DOCX editor/previewer built with React + Vite and `docx` (Node/JS ecosystem).

It lets you:
- Edit Markdown in the left pane
- Live-preview the generated DOCX rendering in the right pane
- Download the final `.docx` file

## Privacy and Local-Only Guarantees
- Per-tab session state management (`sessionStorage`) keeps each tab isolated.
- No cross-tab content overwrite.
- External URL fetch is blocked for images during conversion.
- Only local/same-origin, loopback, `data:` and `blob:` image sources are allowed.
- Designed for fully local workflows with confidential content.

## DOCX Behavior
- Table structures are generated in DOCX format.
- Page number fields are generated by JavaScript (`docx` library).
- Table of Contents/page fields are Word fields and are updatable when opened in Microsoft Word.

## Tech Stack
- React
- Vite
- `@uiw/react-md-editor`
- `docx`
- `docx-preview`
- `file-saver`

## Getting Started
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Typical Workflow
1. Paste or write Markdown in the editor.
2. Validate formatting in the DOCX preview.
3. Click **Download DOCX**.
4. Open in Microsoft Word and update fields if needed (TOC/page fields).
